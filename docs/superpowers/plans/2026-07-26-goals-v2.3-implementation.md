## Global constraints

Same as v1/v2 plans (tenant scoping, smoke guard for new GETs, `runtime='nodejs'`, connectors never throw across the tick, node:test, commit per task). Assisted extraction uses `generateStructured({ model: DEFAULT_SUMMARY_MODEL })`; no fabricated readings (low confidence → throw). `assertSafeUrl` guards every URL fetch (worker shares a network with Redis).

Wizard: KINDS list, unit picker only for custom_kpi, kind→unit+direction on change, lead_gen default recurrence monthly. Catalogue: retag carr→lead_gen/revenue; goal-fit test covers lead_gen. Schema comment + e2e references updated. Tests: unit derivation.
- [ ] **T2 Goal templates.** `src/lib/goals/goal-templates.ts` (20 static entries, invariant-tested: 4/department, 2 org + 2 personal, valid kinds). `/goals` "Start from a template" section with department chips → `/goals/new?template=<key>` prefill (name/kind/recurrence/scope/unit).
- [ ] **T3 URL source.** `src/lib/metrics/sources/url.ts`: `assertSafeUrl` (pure, tested matrix: private/loopback/link-local/metadata/credentials/scheme; 3-hop revalidated redirects), 10s/1MB fetch, JSON dot-path or first-numeric walk, text fallback via Sheets coercion. Registry + tests with injected fetch.
- [ ] **T4 Assisted sources.** `src/lib/metrics/sources/slack-assisted.ts` + `gmail-assisted.ts`: message pull (built-in Slack read / native Gmail proxy top-5 + snippet cap), shared extraction helper (`src/lib/metrics/assisted-extraction.ts`) with `{found, value, confidence, evidence}` schema; found:false or low → throw. Tests with injected transport + generate fakes.

- [ ] **T6 CSV import.** `POST /api/goals/[id]/datapoints/import` (text/csv body, ≤1000 rows, per-line error report, origin backfill, one re-evaluation); pure parser tested; detail-page Import CSV dialog; wizard CSV card → manual goal + deep link `?import=1`.
- [ ] **T7 Verify & docs.** Full gate (typecheck, tests incl. e2e, lint, build); ARCHITECTURE.md sentence for assisted/url/csv ingestion; commit.
